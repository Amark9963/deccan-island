# Deccan Island

Initial public website foundation for Deccan Island, a weekend Hyderabadi dum kitchen in Penang.

## Run locally

```bash
npm install
npm run dev
```

The current build is a public-facing launch page only. Live pre-orders are intentionally disabled until the WhatsApp number, pickup details, service dates, DuitNow QR, policies and allergen information are confirmed.
